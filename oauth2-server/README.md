# Env vars for [configuration](https://github.com/CoachCore/Backend-microservices/blob/dev/oauth2-server/src/main/resources/application.yml)

- `DB_HOST` - host and port for db
- `DB_USERNAME` - username for db access
- `DB_PASSWORD` - password for db access
- `ISSUER` - host and port for issuer uri
- `OAUTH2_WEB_APP_CLIENT_ID` - client id for web app
- `OAUTH2_WEB_APP_CLIENT_SECRET` - client secret for web app
- `OAUTH2_WEB_APP_CLIENT_REDIRECT_URI` - redirect uri for web app client
- `OAUTH2_MAIL_CLIENT_ID` - client id for sending mails
- `OAUTH2_MAIL_CLIENT_SECRET` - client secret for sending mails
- `LOGGING_LEVEL` - logging level
