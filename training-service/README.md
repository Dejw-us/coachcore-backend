# Env vars for [configuration](https://github.com/CoachCore/Backend-microservices/blob/dev/training-service/src/main/resources/application.yml)

- `DB_HOST` - host and port for db
- `DB_USERNAME` - username for db access
- `DB_PASSWORD` - password for db access
- `AUTH_SERVER_HOST` - host and port for oauth2 server
- `LOGGING_LEVEL` - logging level
