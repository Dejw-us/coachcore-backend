# Env vars for [configuration](https://github.com/CoachCore/Backend-microservices/blob/dev/email-service/src/main/resources/application.yml)

- `SMTP_USERNAME` - username for mail sending
- `SMTP_PASSWORD` - password for mail sending
- `AUTH_SERVER_HOST` - host and port for oauth2 server
- `DEV_MODE_ENABLED` - specify whether should send emails or just simulate it
- `LOGGING_LEVEL` - logging level
