# Env vars for [configuration](https://github.com/CoachCore/Backend-microservices/blob/dev/profile-service/src/main/resources/application.yml)

- `AUTH_SERVER_HOST` - host and port of oauth2 server
- `DB_HOST` - host and port of db
- `DB_NAME` - name for db
- `DB_PASSWORD` - db password
- `DB_USERNAME` - username for db access
- `LOGGING_LEVEL` - logging level
- `AWS_S3_BUCKET_NAME` - s3 bucket name for storing user avatars
- `AWS_S3_ENDPOINT` - host and port of s3 service
- `AWS_ACCESS_KEY` - access key for aws
- `AWS_SECRET_KEY` - secret key for aws
- `AWS_REGION` - aws region
